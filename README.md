# Sistema de pedidos en consola (C)

Este programa es un ejemplo básico de una aplicación de domicilios hecha en lenguaje C. Funciona desde consola y permite al usuario realizar pedidos de forma sencilla.

## ¿De qué trata?

El sistema muestra un menú donde el usuario puede escoger diferentes opciones como ver productos, agregar pedidos y consultar el total a pagar.

La idea principal es aplicar estructuras de control y lógica de programación en un caso práctico.

## Opciones del menú

- Ver lista de productos
- Agregar productos al pedido
- Mostrar pedido actual
- Confirmar pedido
- Salir del programa

## Herramientas utilizadas

- Lenguaje C
- Uso de `struct` para organizar datos
- Ciclos (`for` y `do-while`)
- Condicionales (`if` y `switch`)
